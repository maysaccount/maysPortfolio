2D Coin Vacuum

Race an evil vacuum to 35 coins before 100 seconds run out. Fake coins cost you a point.

UnityC#

Controls

The player uses Vector3 directions on the x and y axis. Speed is a public int so it's easy to configure in the Inspector. The enemy only moves if there is a coin in the scene, and then heads towards it on the x and y axis. It picks the coin closest to it, which makes the race a challenge.

Score managers

Score starts at 0. Touching a coin adds 1 to the text on the canvas; touching a fake coin takes 1 away. The enemy has its own ScoreManager doing the same thing.

Coin spawning and despawning

Coins spawn at a random point in the scene every 2 seconds, and fake coins every 3 seconds, checked with a Time.deltaTime timer. If a coin hasn't been collected after 10 seconds it is removed.

Timer

The timer takes one off every second using Time.deltaTime. If the player's score is over 35 before it ends they win. At 0 the scene reloads to restart the game.
