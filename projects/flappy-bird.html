Flappy Bird

A 2D side-scroller. Every pipe you get past is a point. Touch one and the game resets.

UnityC#

PlayerController

Speed is a public float so it's easy to change. When space is pressed the Rigidbody transforms its position, multiplied by the horizontal axis and the speed.

RestartPlatform

The game doesn't restart unless something with the Player tag triggers this platform. When it does, the player goes back to (0, 0) as the scene resets.

PlatformMove

Pipes move left at speed 1 until they reach x = -13, then they're destroyed so there aren't useless objects running in the background.

Score and GameManager

The score goes up when the player hits the trigger inside the pipe prefab, and the TMP text updates to match. The GameManager sets the score to 0 and puts it back to 0 after a restart.

SpawnPrefab

The square brackets on the public GameObject tell the code it's a list of prefabs. After the timer passes 1.5 seconds one is picked at random and instantiated, then the timer resets.

Typed up: SpawnPrefab.cs — pick a random pipe
